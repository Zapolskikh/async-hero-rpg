# Async Hero — персонажи V2

Переработанные цельные персонажи в простой геометрической стилистике Б: мужчина и женщина. Длинные рукава, брюки, сапоги, закрытые суставы. По семь статичных видов: без оружия, меч, два меча, меч со щитом, двуручный меч, лук, посох. Всего 14 спрайтов.

## Что открыть

- `preview.html` — автономное сравнение всех вариантов с переключением пола и направления.
- `overview.png` — общий обзор.
- `preview_game_scale.png` — проверка в небольшом игровом размере.
- `sprites/` — прозрачные PNG 512×512.
- `sprites_256/`, `sprites_128/` — уменьшенные экспорты.
- `source_art/` — исходные изображения и полный набор промптов. Рисунки созданы встроенным imagegen; нормализация, экспорт и маски подготовлены программно.
- `layers/<пол>/<вид>/` — три слоя PNG на одном холсте: `artwork`, `skin`, `hair`; плюс две маски материалов.
- `manifest.json` — размеры, область изображения, направление и точка привязки к земле.

## Использование

Все основные PNG имеют прозрачный холст 512×512 и общую линию подошв y=400. Используйте точку опоры `[256,400]`; уменьшайте весь холст равномерно. Пример: при масштабе 0.5 холст станет 256×256, а опора — `[128,200]`. Для направления влево отразите весь спрайт и его опору. Рекомендуется линейная фильтрация. Оружие входит в область спрайта: не обрезайте автоматически прозрачные поля без сохранения смещения.

Слои `artwork → skin → hair` в этом порядке точно восстанавливают соответствующий готовый PNG. Они разделены по материалу для перекраски, а не по костям. Для смены цвета сохраняйте яркость исходного материала и альфа-канал. Тёмный контур остаётся в `artwork`.

Это статичные виды покоя с нарисованным хватом под каждый тип оружия. В архиве нет новой анимации, готового рига или импортированного проекта движка. Оружие и одежда нарисованы внутри позы; это не отдельные взаимозаменяемые предметы инвентаря. Готовые PNG позволяют проверить внешний вид без повторной сборки старого скелета. Для последующего рига нужны отдельные части с дорисованными перекрытиями и привязкой под конкретную систему анимации.

Эта версия не использует суставы и разрезанные конечности из V1. Не подставляйте новые изображения в прежний риг: используйте цельные PNG, чтобы получить именно вид из обзора.
