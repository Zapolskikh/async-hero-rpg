# Персонажи и анимации V3

Источник: пользовательский `async_hero_animation_v3.zip`. Используется контроллер из `godot/actor.gd`, а не прежние PNG V2 с дорисованными руками. Инструкции: [V3_AGENT_PROMPT_RU.md](V3_AGENT_PROMPT_RU.md); описание набора: [V3_README_RU.md](V3_README_RU.md).

## Ресурсы

`assets/characters/v3/` содержит две головы и два набора JSON: по 47 клипов для мужчины и женщины. JSON упакованы стандартным gzip без изменения исходных данных. SHA-256 распакованных файлов записан в `source_manifest.json`. Размер данных уменьшен примерно с 28 до 4.8 МБ. Web и Android включают `*.gz` через `include_filter`.

Повторный импорт ресурсов: `python tools/import_v3_data.py async_hero_animation_v3.zip`. Импортёр не перезаписывает игровой контроллер. V2 и прежний `WeaponMotion` удалены из runtime. Сохраняются выбор пола, портреты, экипировка и сохранённые значения внешности; выбор причёски остаётся скрытым по решению пользователя.

## Управление

`V3RigActor` воспроизводит исходные команды рисования, суставы и сокеты. Геометрия, длины конечностей и траектории берутся из архива. `CharacterActor` выбирает клип по оружию и событию игры. Семь комплектов: без оружия, меч, два меча, меч со щитом, двуручный меч, лук, посох. Прежний сдвиг всего персонажа отключён: движение корпуса уже содержится в клипе, стопы остаются на земле.

Лук находится в анатомически левой руке, правая натягивает тетиву. Стрела скрывается при выпуске и появляется при подготовке следующего выстрела. Два меча используют попеременные удары правой и левой рукой; массовый удар может использовать `dual_combo`. Удар щитом использует `shield_bash`. Посох не делает физическую автоатаку. Магия использует подготовку, удержание и выпуск; долгий арканный каст с посохом использует `staff_cast_*`, остальные — жест правой рукой текущего комплекта. Двуручный хват отпускается и возвращается по данным клипа. Свечение привязано к кисти или навершию и окрашено цветом заклинания.

Сокеты: `right_hand`, `left_hand`, `cast_right`, `right_weapon_tip`, `left_weapon_tip`, `staff_tip`, `arrow_muzzle`, `shield_front`. Мировые трансформации учитывают масштаб и отражение персонажа. Начало снаряда и эффекты удара берутся из маркеров клипа.

## Время и события

В бою только `BattleView` обновляет персонажей; вложенный риг не получает дополнительный `_process`. События симуляции содержат время, поэтому при длинном кадре позы последовательно обновляются до каждого события. Один масштаб времени применяется к симуляции и визуализации. В тренировке доступны пауза и скорости 0.25×, 1×, 2×, 4×, 8×.

Каждое внешнее действие получает ID. Событие клипа срабатывает только один раз, включая границы кадров. Переходы begin → hold и draw → release сохраняют остаток времени кадра. Прерывание, оглушение, смерть и смена комплекта отменяют ожидаемые выпуски. Обычное попадание не сбивает позу каста.

Маркеры управляют только изображением: выпуском снаряда, эффектом и подписью урона. Урон не наносится повторно. Здоровье и результат боя определяет симуляция; полоски здоровья обновляются сразу, подпись попадания может появиться позже, при контакте. Отмена визуального действия не отменяет уже рассчитанный симуляцией урон.

## Проверки

Сначала запущено отдельное демо из архива и его `validate.gd`: 94 клипа, 0 ошибок. Проверки интеграции:

```text
godot --headless --script res://tests/v3_reference_tests.gd
godot --headless --script res://tests/weapon_motion_tests.gd -- --qa
godot --headless --script res://tests/character_tests.gd -- --qa
godot --headless --script res://tests/training_tests.gd -- --qa
godot --script res://tests/v3_visual_tests.gd -- --qa
godot --script res://tests/v3_battle_preview.gd -- --qa
```

Проверяются все 94 клипа, длины плеча/предплечья, опора стоп, двуручный хват, обе стороны, семь комплектов, удержание каста 0.2/2/10 секунд, повторные действия, отмена, длинный кадр, пять скоростей, однократный выпуск стрелы и отсутствие повторного урона. Для вторичного хвата допускается до 0.6 пикселя погрешности линейной интерполяции между исходными позами.

Нативный Godot сохраняет увеличенные листы клипов, магические жесты, экраны героя/тренировки и кадры боя в `build/qa/v3/`. Это локальные результаты QA, они не входят в игру. `--qa` изолирует проверки от пользовательского сохранения.

## Ограничения набора

В V3 нет клипов ходьбы и смерти. После смерти используется остановка позы и плавное исчезновение. Набор даёт базовые силуэты семи комплектов, но не отдельные анимированные варианты для каждого предмета брони и оружия. Враги продолжают использовать существующие спрайты. Баланс, расчёт боя и набор способностей этим обновлением не меняются.
