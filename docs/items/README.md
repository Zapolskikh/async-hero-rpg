# Вещи: список для отрисовки

[items_for_art.json](items_for_art.json) содержит весь каталог: виды, вещи и эффекты. Собирается командой `python tools/gen_items.py`.

Задание для художника собирается отдельно:

```text
python tools/build_art_brief.py
```

Команда создаёт `async_hero_gear_brief.zip`: промпт, шаблоны деталей из атласа героя, список файлов и инструменты проверки. Источники лежат в `tools/art_brief/`.

Экипировка рисуется по деталям, а не цельным предметом: герой собран из отдельных вращающихся частей. Иконки амулетов и аксессуаров в задание не входят.

Готовые рисунки подключаются командой `python tools/build_gear_atlas.py <архив>`. Игра показывает их на героях и наёмниках через поле `look` вещи.
