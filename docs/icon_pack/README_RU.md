# Async Hero — пиксельные иконки

Полный комплект: **134 иконки** — 64 таланта, 50 доступных игроку заклинаний, 3 скрытых совместимых заклинания и 17 способностей противников. Для рангов используются те же изображения.

Стиль согласован по пробам «Огненный шар», «Ледяная стрела», «Цепная молния» и «Обновление». Эти четыре рисунка сохранены без новой генерации. «Пинок» сохранён из исходной демоверсии по просьбе пользователя.

## Файлы

- `assets/icons/` — все 134 PNG RGBA **16×16**, готовые для замены файлов по путям из каталога.
- `icons_32/` — те же иконки **32×32**.
- `icons_64/` — те же иконки **64×64**, лучше сохраняют детали согласованных рисунков.
- `masters/` — исходные изображения с прозрачностью, без изменения рисунка.
- `atlases/icons_16.png`, `icons_32.png`, `icons_64.png` — атласы; 14 колонок, порядок и координаты в manifest.json. Между ячейками нет отступов.
- `previews/` — листы по разделам: слева версия 64×64, увеличенная до 96×96, справа версия 16×16, увеличенная до 64×64.
- `overview.png` — общий лист всех иконок.
- `catalog.csv` — таблица ID → имена → файлы → референсы.
- `manifest.json` — метаданные, ссылки на референсы, промпты, проверочные суммы и координаты в атласах.
- `SOURCE_CATALOG_RU.md` — исходный каталог механик.

## Подключение

Скопировать `assets/icons/` в проект для текущих путей и размера. Для более детальных иконок использовать `icons_32/` или `icons_64/`, сохраняя логический размер элемента интерфейса. Экспорт размеров выполнен nearest-neighbor с бинарной прозрачностью. Широкие композиции вписаны в квадрат без растяжения, с прозрачными полями. В Godot выбрать фильтрацию **Nearest**, отключить mipmaps; для атласов без отступов это особенно важно. Рамки, редкость, затемнение и индикаторы ранга рисует интерфейс.

Версия 16×16 сохраняет совместимость с текущим каталогом; при таком размере часть мелких деталей согласованного рисунка теряется. Версии 32×32, 64×64 и исходники приложены отдельно.

## Происхождение и объём

Новые рисунки сделаны встроенным imagegen по конкретным референсам иконок World of Warcraft с изменением контуров, деталей и пиксельной адаптацией. Точные имена и URL исходных референсов перечислены в catalog.csv и manifest.json. Для талантов использованы подходящие по смыслу иконки пассивных эффектов и способностей WoW. Исходная иконка demo «Пинка» принадлежит загруженным материалам пользователя.

Комплект содержит только статические иконки. Боевые VFX, спрайты персонажей и анимации сюда не входят. Для каждой иконки: один кадр, FPS 0, loop=false; pivot (8,8) для версии 16×16, центр для других размеров. Числа баланса не зашиты в рисунки.
