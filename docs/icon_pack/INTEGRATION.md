# Подключение комплекта иконок

В `assets/icons/` установлены все 134 PNG из `icons_64/` пользовательского архива `async_hero_wow_pixel_pack.zip`: 64 таланта, 50 выбираемых заклинаний, 3 скрытых заклинания и 17 способностей противников.

Сохранены имена `tal_<id>.png` и `sp_<id>.png`; интерфейс использует их по прежним путям. Размер текстур — 64×64 RGBA, размеры элементов интерфейса прежние, фильтрация Nearest, mipmaps отключены. Версии 64×64 выбраны для сохранения деталей рисунков. «Пинок» использует переданную пользователем иконку ботинка.

`README_RU.md` и `catalog.csv` в этой папке — исходные сопроводительные файлы архива. Описанные там размеры 16×16/32×32, атласы и masters остаются в исходном ZIP; в игру подключены индивидуальные PNG 64×64.

`tools/build_combat_data.py` создаёт заглушку только при отсутствии файла и не перезаписывает установленную графику. Архив пользователя не изменён.
