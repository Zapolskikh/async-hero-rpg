# Отчёт о силе способностей

Дата прогона: 1 ноября 2026, коммит d0b4ac7 плюс отчёт `tests/spell_power_report.gd`. Это первый прогон. **Список аномалий ниже ещё нельзя брать в правки**, причины в разделе «Ограничения».

## Итоги

- Полный прогон: 24 мин 57 с в одном процессе, 35 760 боёв, около 42 мс на бой. С 20 сидами примерно 13 минут.
- `cleanse` и `purge` без кулдауна сыграли хуже, чем с кулдауном 8 с: в первом слоте они забирают ходы у урона.
- Тиры не выстраиваются лесенкой: обычная `mortal_strike` сильнее всего остального урона, легендарные `beast`, `seed` и `bladestorm` ниже нуля.

## Как читать оценки

Группа из четырёх героев с одинаковыми статами сражается с настоящими врагами. Силу врагов подбираем так, чтобы группа с одним филлером `arcane_bolt` заканчивала бой с запасом около 0.

- **Запас боя:** при победе это доля оставшегося здоровья группы, при поражении — минус доля оставшегося здоровья врагов.
- **Оценка:** запас с ротацией `[способность, филлер]` минус запас только с филлером, на тех же сидах. 0 значит «столько же, сколько простая атака». Диапазон от −2 до +2.
- **Танковые способности** ставятся танку, и их филлер — `strike`.
- **Итоговая оценка:** для утилити это лучший сценарий, для остальных ролей — среднее по сценариям.
- **Аномалия:** отклонение от медианы своей роли и тира больше `max(0.05, 2 MAD)`. Если в группе меньше 3 способностей, сравниваем со всей ролью.

Запуск:

```
godot --headless --path . --script res://tests/spell_power_report.gd -- --seeds=40 --out=report.md
```

Опции: `--seeds=N`, `--levels=10,20,30`, `--only=heal,cleanse`, `--out=path.md`.

## Сравнение: диспеллы с кулдауном и без

Значения сверху по сценариям, 40 сидов. Больше — лучше. Вариант с 8 с запускался на временно изменённых данных, в `db.gd` остался кулдаун 0.

|---|---|---|
| `purge`, `ward` | +0.26 | −0.54 |
| `purge`, `poison` | −0.06 | −0.14 |
| `purge`, `casters` | −0.16 | −0.18 |
| `cleanse`, `poison` | −0.08 | −0.24 |
| `cleanse`, `casters` | −0.39 | −0.39 |

`cleanse` проигрывает простой атаке даже с кулдауном 8 с. Предложение: поставить обоим диспеллам кулдаун 3–4 с и проверить заново. Решение ещё не принято.

## Ограничения

1. **Сценарий `ward` слишком резкий.** Там бой решает небольшая разница в уроне: `rend` получает −1.65. Этот сценарий определяет средние оценки, поэтому ниже есть рейтинг без него.
2. **Оценка утилити искажена.** Берётся лучший сценарий, поэтому `cleanse` получил 0.00 там, где не срабатывал, а итоговый статус «слишком слабая» считался по этому значению.
3. **Способность всегда стоит в первом слоте.** Ротация идёт по приоритету слотов, поэтому за `arcane_bolt` без кулдауна она не сработает. Нужен филлер с кулдауном.
4. **Таланты не учитываются.** Комбинации с талантами ещё не проверены.
5. **`arcane_bolt` помечен «не срабатывает» ложно.** Это сам филлер, его оценка равна нулю по определению.
6. **Низкая оценка `aimed_shot` не объяснена.** Предположение: во время каста герой не делает автоатаки. Отдельно не проверялось.
