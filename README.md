# Async Hero RPG — прототип

Играбельный прототип AFK/async RPG по концепту v0.3. Движок Godot 4.5 (GDScript), горизонтальный экран, графика временная: простой пиксель-арт, сгенерированный скриптом.

## Как запустить

**В браузере (в том числе с телефона):** https://zapolskikh.github.io/async-hero-rpg/ — каждый push в `main` автоматически собирает и публикует Web через GitHub Actions. В Settings → Pages выбран Source: GitHub Actions. Телефон лучше повернуть горизонтально.

**В редакторе:**

1. Скачайте Godot 4.5 (обычная версия, не .NET): https://godotengine.org/download
2. Import → выберите `project.godot` из этого репозитория.
3. F5 (Run Project).

Сохранение лежит в `user://save.json`. Сбросить прогресс можно кнопкой внизу вкладки «Сумка».

## Онлайн

Шестерёнка в правом верхнем углу → адрес сервера → «Подключиться». В веб-версии адрес можно передать в ссылке: `…/async-hero-rpg/?server=https://api.ваш-домен`. Онлайн-аккаунт отдельный от офлайн-сохранения; вернуться в офлайн можно там же. Как поднять сервер — [server/README.md](server/README.md).

## Структура

```
scripts/data/db.gd          — все данные: способности, враги, уровни, шаблоны наёмников
scripts/data/professions.gd — профессии: ресурсы, локации, рецепты, зелья, дроп ткани и с боссов
scripts/sim/battle_unit.gd  — боец
scripts/sim/battle_sim.gd   — детерминированная симуляция боя (шаг 0.1 с, seed)
scripts/sim/expedition.gd   — поход: волны, push/farm, награды, офлайн-досчёт
scripts/core/roster.gd      — снапшоты героя и наёмников, доска наёмников
scripts/core/loot.gd        — генерация снаряжения
scripts/core/rules.gd       — ВСЕ правила игры над профилем-словарём (общие для клиента и сервера)
scripts/core/game_state.gd  — автозагрузка Game: профиль, живая копия боя, офлайн/онлайн
scripts/core/net.gd         — HTTP-клиент к серверу
worker/worker.gd            — процесс правил для сервера (Godot headless, JSON-строки)
server/                     — сервер: FastAPI, PostgreSQL, Docker, Caddy, тесты
scripts/ui/                 — интерфейс (строится кодом) и отрисовка боя
tests/                      — тесты и отчёт по балансу
```

Логика боя не зависит от сцен и интерфейса, поэтому её можно запускать без экрана (тесты, офлайн-досчёт), а позже перенести на сервер.

## Интерфейс

Плоский мобильный стиль: тёмные карточки, цветные кнопки с объёмом, нижняя панель вкладок, полоса ресурсов сверху, красные точки на вкладках, где что-то ждёт.

- **Все цвета, скругления и размеры шрифтов — в `scripts/ui/style.gd`.** Чтобы перекрасить игру, достаточно поменять этот файл.
- Готовые элементы (карточка, кнопка, плитка, плашка-ресурс, прогресс, бейдж, аватар) — в `scripts/ui/ui.gd`.
- Экраны — в `scripts/ui/main.gd`: «Поход» (карта кампании, живой бой, карточка уровня), «Герой» (кукла, ротация, способности), «Наёмники» (состав и доска), «Заклинания» (Spell Box и коллекция), «Сумка» (предметы и сравнение). Экран «Ремёсла» — `scripts/ui/crafts_screen.gd` (вкладки «Сбор», «Ремесло», «Материалы»).
- Иконки генерирует `tools/gen_icons.py` в `assets/icons/` (превью — `tools/icon_sheet_preview.png`).

## Графика

**Кукла героя.** Герой рисуется слоями: `assets/units/doll_body.png` и поверх по слою на каждую надетую вещь (`doll_head`, `doll_armor`, `doll_hands`, `doll_legs`, `doll_feet`, `doll_trinket`, `doll_shield`, `doll_offhand_sword`, оружие `doll_w_sword` / `doll_w_greatsword` / `doll_w_staff` / `doll_w_bow`). Все слои в одной рамке 34×42, герой смотрит вправо. Слои вещей нарисованы светло-серым и окрашиваются по редкости (`Roster.LOOK_TINTS`), оружие — своими цветами. Генератор — `tools/gen_doll.py`, любой PNG можно заменить своей картинкой того же размера и имени.

Вся графика временная и генерируется скриптом `tools/gen_sprites.py` (нужен Python с Pillow):

```
python3 tools/gen_sprites.py
```

Спрайты лежат в `assets/units/<id>.png` (персонаж смотрит вправо, врагов игра отражает сама), фон — в `assets/bg/`. Чтобы поставить настоящий арт, достаточно заменить PNG с тем же именем. Превью всех спрайтов: `tools/sprite_sheet_preview.png`.

Анимации делаются кодом в `scripts/ui/battle_view.gd`: дыхание, выпад при ударе, отдача при попадании, снаряды и стрелы, свечение при касте, вспышки лечения и щитов, падение погибших.

## Тесты и баланс

```
godot --headless --script res://tests/run_tests.gd        # детерминизм, ротация, interrupt, вайп, офлайн
godot --headless --script res://tests/rules_tests.gd      # общие правила: таймлайн, сбор, лимиты, проверки, найм игроков
godot --headless --script res://tests/balance_report.gd   # минимальный уровень героя для каждого уровня и состава
```

Текущий отчёт по балансу (минимальный уровень героя без снаряжения, при котором группа проходит 4 попытки из 6):

| Уровень | Сбалансированная | 4 DPS | 2 лекаря | Interrupt + лекарь |
|---|---|---|---|---|
| 1 Опушка | 1 | 1 | 1 | 1 |
| 3 Тёмная роща | 2 | 3 | 2 | 2 |
| 5 Логово вождя | 5 | 8 | 5 | 6 |
| 8 Крепость стражей | 10 | 17 | 12 | 12 |
| 10 Склеп лича | 16 | 21 | 16 | 18 |

Состав без лечения отстаёт всё сильнее, как и задумано в концепте.

## Веб-сборка

Пресет `Web` в `export_presets.cfg` (без потоков, чтобы работало на GitHub Pages без особых заголовков). Размер холста на телефонах считает скрипт из `web/head_include.html` (он же вписан в пресет): по видимой области `visualViewport` с учётом выреза и полоски «домой», поэтому после поворота экрана игра не съезжает. При изменении `web/head_include.html` нужно обновить строку `html/head_include` в пресете.

```
godot --headless --export-release "Web" build/web/index.html
```

Публикация выполняется автоматически из `main` workflow-файлом `.github/workflows/web.yml`: проверки → экспорт с версией в именах файлов → GitHub Pages. Ветка `gh-pages` больше не используется для актуального сайта. Версию опубликованной сборки можно проверить в `/async-hero-rpg/version.json`. Обновление кэша не удаляет сохранения; для уже открытой игры появляется кнопка обновления.

## Темп прохождения

```
godot --headless --script res://tests/pacing_report.gd
```

Симулирует простого игрока: штурмует следующий уровень тремя разными составами, при неудаче 5 минут фармит последний пройденный и пробует снова. Печатает время на каждый уровень и уровень героя. Оценка консервативная: у героя нет снаряжения, наёмники обычного качества.

Текущий результат: вся кампания около 2,3 ч игрового времени. Обычные уровни 1–4 мин, стены на концах глав: 10-й около 13 мин, 20-й около 20, финал 29–30 по 22–23 мин. Герой к 30-му уровню — около 40-го.

Ручки настройки в `scripts/data/db.gd`: `GOLD_MULT` (множитель всего золота), `XP_SLOWDOWN_FROM` и `XP_SLOWDOWN_POW` (с какого уровня героя и насколько круто дорожает опыт), `LEVEL_SCALE` (рост врагов в 1-й главе), `HERO_AT_BREAK` и `HERO_PER_LEVEL` (под какой уровень героя растут враги после 10-го), `LATE_TOUGHNESS`, `xp_level_factor` и `xp_to_next` (скорость прокачки).

## Скриншоты для разработки

`godot -- --shots=<папка>` проходит по всем экранам, запускает бой и сохраняет скриншоты. С `--shots-crafts`, `--shots-spells` или `--shots-weapons` снимает только экраны профессий, заклинаний или оружия.

## Профессии

Все цифры — в `scripts/data/professions.gd`:
- `LOCATIONS`: добыча в час, редкие находки, опыт;
- `DURATIONS`: длительности и их эффективность;
- `RECIPES`: ингредиенты, золото, время, опыт, результат;
- `CONSUMABLES`: эффекты зелий;
- `CLOTH_BY_LEVEL`, `BOSS_DROPS`: что падает в бою.

Правила:
- Сбор и ремесло хранят только `started_at` и `ends_at`. Результат выдаётся при «Забрать», и только после `ends_at`. Повторное «Забрать» ничего не даёт.
- Онлайн время ставит сервер.
- Материалы из боя считаются отдельным генератором случайных чисел, поэтому баланс боя от них не меняется.

## Каталог для графики и тренировка

[Полный список талантов и заклинаний для иконок и анимаций](docs/ART_CATALOG_RU.md): 64 таланта, 50 выбираемых заклинаний, скрытые записи совместимости и способности противников. Генерация из текущих данных: `python tools/export_art_catalog.py`.

«Герой → Манекен» открывает отдельный живой тренировочный бой. Все 50 заклинаний доступны без владения копиями; можно менять три слота прямо в бою, выбирать ранг 1–10, тип оружия, одну или три цели, ответные атаки и цели с 20% HP для добивания. Союзники начинают с 55% здоровья для проверки лечения. Пресеты оружия сохраняют остальные характеристики героя, поэтому это проверка механик, а не сравнение полных комплектов снаряжения. Есть пауза, сброс боя и счётчики DPS/HPS. Один бой длится до 150 секунд; повтор запускается сбросом. Сохранённый набор, коллекция, награды и текущий поход не меняются.

Проверка тренировки: `godot --headless --script res://tests/training_tests.gd -- --qa`. Без `--headless` тест также сохраняет снимок `build/qa/training.png`.

## Внешность персонажа

«Герой → Внешность»: мужская/женская модель, предпросмотр и бесплатное сохранение. Модели V2 собраны в cut-out риг (`tools/build_character_rig.py`), он работает в портретах, бою и тренировке: по 56 клипов для каждого пола, семь комплектов оружия. Удары, натяжение лука, касты и падение построены на ключевых позах с корректными локтями, коленями и переносом веса. Смена причёски временно скрыта. Внешность сохраняется и передаётся через сервер, не влияет на характеристики. В тренировке есть пауза и скорости 0.25×–8×. [Подключение, проверки и ограничения набора](docs/characters/INTEGRATION.md).

Проверка: `godot --headless --script res://tests/character_tests.gd -- --qa`.
